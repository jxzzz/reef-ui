# @reef-ui/theme

[![npm version](https://img.shields.io/npm/v/@reef-ui/theme?color=cb3837&logo=npm)](https://www.npmjs.com/package/@reef-ui/theme)

Reef UI 的 Design Token 包:颜色、间距、圆角、阴影统一由 `--reef-*` CSS Variables 提供,内置暗色主题(`data-theme="dark"` 自动翻转)。

```bash
npm install @reef-ui/theme
```

```tsx
import '@reef-ui/theme/css';
```

配合 [`@reef-ui/components`](https://www.npmjs.com/package/@reef-ui/components) 使用,详见 [Reef UI 文档](https://reef-ui.imxuex.workers.dev)。
